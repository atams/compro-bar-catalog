# Midnight Mixology | Premium Bar Catalog

An immersive, high-end digital catalog for fine spirits and artisanal cocktails. Designed with a "Midnight" aesthetic, featuring advanced cinematic animations, 3D interactions, and a luxury-first user experience.

## ✨ Features

- **Cinematic Experience**: Custom GLSL Nebula background and smooth page reveals.
- **Premium Animations**: 
  - Magnetic Glow Pill Buttons.
  - Wavy Letter Navigation Reveals.
  - Liquid Mouse Trail tracking.
  - 3D Flip & Parallax Catalog Cards.
- **Responsive Mastery**: Fully optimized for mobile with a floating "Quick Menu" for instant access.
- **High-End Design System**: 
  - Midnight Mixology Palette (Rich Black, Champagne Gold, Viva Magenta).
  - Editorial Typography (Cinzel Decorative, Playfair Display).
  - Architectural Iconography (Thin-stroke 1.2pt).

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **3D Engine**: [React Three Fiber](https://r3f.docs.pmnd.rs/) & [Three.js](https://threejs.org/)
- **Package Manager**: [Bun](https://bun.sh/)

## 🛠️ Getting Started

First, install the dependencies:

```bash
bun install
```

Then, run the development server:

```bash
bun dev
```

Open [http://localhost:5000](http://localhost:5000) with your browser to see the result.
